PRICINGPILOT - CUSTOMER HANDOFF DRAFT
Release status: testing candidate, not cleared for commercial delivery.

OPENING
For a controlled review installer, first read SETUP-NOTICE. Double-click
PricingPilot-Review-Setup.exe, then launch PricingPilot Review from its Desktop
or Start Menu shortcut. Setup is per-user; no Node/Python commands or API key
are needed. Edge must already be installed. Stop at any security-policy warning;
do not bypass protections. This unsigned candidate is not cleared for sale.

For a source-folder review:
Keep index.html and its css, js and lib folders together. Open index.html in
Microsoft Edge. No account, API key, payment or dependency installation is needed
for the local calculator. Edge/file-launch tests pass with synthetic data in
fresh profiles. Your own browser/profile storage still needs careful backups.

MAKE A QUOTE
1. Enter labor hours, hourly labor cost, materials, other costs, overhead and
   target profit margin. The hourly cost is your input assumption, not market data.
2. Calculate. Margin is profit divided by selling price, not markup on cost.
   Example: cost $100 at 40% margin yields $166.67, not $140.
3. Review Budget, Standard and Premium prices and margins. Tier multipliers
   change price only; they do not recalculate costs for upgrades or extra work.
   If the scope changes, update costs separately before approving the price.
4. Edit tier inclusions and confirm actual materials, exclusions, scheduling,
   warranties and charges. Default text is a prompt, not an agreed promise.
5. Enter business/service details and render the quote. Leave the internal
   profit-margin checkbox OFF for customer copies. Verify the output yourself.
6. Print or save as PDF with the browser. The default customer and internal
   layouts have been verified as one Letter page. Detailed quotes automatically
   use a multi-page table layout with repeated tier headings instead of narrow
   cards. A long-name/64-inclusion stress example was visually reviewed across
   five pages with no missing inclusion markers. Inspect your actual PDF;
   this does not guarantee every possible content length or printer setting.
7. Copy quote as text uses clipboard access where available. If access fails,
   the app reports the failure and exposes selectable text for manual copy.

CHANGES AND SAVING
Changing cost inputs invalidates the old price and quote. Calculate and render
again. Tier edits update the scenario and invalidate the rendered quote.
Name a scenario and save it. If storage fails, the app shows a warning; do not
assume a quote was saved. Verify it appears in the list and reloads correctly.
Use the Editing tab for saved changes. The app uses a browser-level lock to give
only one tab editing access; other tabs clearly show View-only, disable saving,
outcome changes and restore, and keep calculations as temporary scratch work.
Backups remain available. Close the editing tab, preserve any reader draft with
a backup, then use Reload latest data to acquire editing access. Reload discards
temporary scratch edits in favor of the latest saved scenario. Browsers without
safe locking stay view-only; use supported Microsoft Edge. This protects tabs
running this version at the same app path, not older app versions or different
profiles/copies. There is no collaboration or shared cloud database.

WHERE YOUR DATA LIVES
Scenarios and quotes use this browser's localStorage. There is no shared team
database or cloud backup. Another browser, profile, machine or location may not
show the same quotes. Private browsing or clearing browser data can remove them.
Moving this folder may change access to file-origin storage. Do not rely on
these browser records as your only business record.

BACKUP AND RESTORE
Open Backup & restore below Saved quotes. Download full backup saves a local
versioned JSON file containing the current form, saved quotes, cost assumptions,
custom tier names/inclusions, competitor values, tax settings, what-if fields,
outcomes and the unsaved quote name. The file contains private cost information;
keep it secure. Download confirmation means a download was requested: check that
your browser actually saved the file before clearing or moving browser storage.

Choose that JSON file to see a restore preview. Merge is the default: it keeps
your current draft, skips identical records and gives differing ID collisions
new IDs. Replace restores the library and current scenario; it removes the old
library only after confirmation. Before either operation, a raw recovery snapshot
download is requested. Keep it. The app keeps an undo journal while restoring;
failed/interrupted writes roll back or leave the journal for recovery on reload.
If recovery cannot finish, stop editing, keep the page open, download raw recovery
data and resolve browser storage availability. Do not manually clear that journal.

Malformed/unsupported backups are rejected without writes. Version 1 supports
up to 1,000 saved quotes and 5 MB; invalid or unsupported original records should
be retained with Download raw recovery snapshot instead of normal JSON export.
Raw recovery snapshots preserve stored bytes and the visible draft but are NOT
directly importable. They may require technical recovery. No automatic cloud
upload or backup service is present. After replacement, internal margins are off;
calculate and render a new quote before sharing.

CSV EXPORT IS NOT A FULL BACKUP
Exported CSV contains quote names, dates, prices and margins, not the full
scenario or inclusions. Use the full JSON backup to transfer complete scenarios.
Save approved quote PDFs and retain source assumptions in your own records.
CSV names that could be formulas are prefixed with an apostrophe for safety.

LIMITATIONS
The product uses local calculations and templates, not a working AI service.
Competitor positioning only compares the prices you supply; it does not research
competitors or verify that their scope matches yours. Prices exclude tax unless
you explicitly accounted for it. Review rounding and every quote before use.
Won/lost statuses are labels you enter. The displayed won quoted value is an
estimated base-price total, not actual payments received or verified revenue.
Invalid saved prices are disclosed and excluded without deleting their records.
No subscription checkout, multi-user service or guaranteed pricing outcome is
implemented. An installer candidate passed isolated install, installed-payload
workflow and uninstall checks on the development PC. The normal Desktop/Start
Menu/registry flow and a separate clean Windows machine still need acceptance,
along with commercial delivery approval. The app is not cleared for sale.
